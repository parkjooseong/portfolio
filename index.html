개발 배경

계약 내용을 충분히 이해하지 못한 채 불리한 조건을 받아들이는 소상공인의 문제에 주목했습니다. 부산 관광상권 소상공인이 광고대행 계약을 확인하고 조정을 준비할 수 있도록, 팀이 AI 계약 관리 서비스를 만들었습니다.

담당 업무

문서 업로드·분석 결과 조회·역제안 비교 등 백엔드 기능을 구현하고, 데이터베이스와 외부 AI API를 연결했습니다.

개발 노트 역제안 비교와 데이터 연동

AI 비교 오류 처리

문제
외부 AI 호출에 오류가 나거나 비교 결과가 잘못되면 역제안 비교를 완료할 수 없었습니다.
해결
상대방의 제안과 사유를 먼저 저장하고 AI 비교를 별도로 처리했습니다. 비교 결과의 항목 ID를 검증하고, 오류가 나도 저장된 원문은 유지하도록 했습니다.

담당자 간 데이터 연동

문제
조정 기능과 AI 비교 기능의 담당자가 달라, 요청·응답·비교 결과를 같은 항목 기준으로 연결해야 했습니다.
해결
공통 항목 ID로 데이터를 연결하고 조정 상세 조회에 비교 서비스를 추가했습니다. 응답 형식과 공유 API 명세도 함께 수정했습니다.

개발 배경

사람들에게 잘 알려지지 않은 책 중에도 지금의 관심사와 연결되는 책이 많습니다. 대출이 적다는 이유로 놓치고 있던 책을 다시 발견할 수 있도록, 팀은 도서관 데이터와 트렌드를 연결하는 추천 서비스를 만들었습니다.

담당 업무

회원 인증과 개인 책장 API를 구현했습니다. 팀의 추천 기능에서는 도서관 조건에 맞춰 최종 후보를 고르는 로직을 보완했습니다.

개발 노트 추천 후보 보충과 API 연동

추천 도서 수 부족

문제
상위 후보를 먼저 고른 뒤 도서관 이용 가능 여부를 검사해, 탈락한 책만큼 추천 도서 수가 줄었습니다. 적합한 차순위 후보도 결과에서 빠졌습니다.
해결
중복 없이 도서관 조건을 통과한 책만 추천 권수에 포함하도록 변경했습니다. 부족한 권수는 차순위 도서와 다음 트렌드의 유효한 후보로 보충했습니다.

프런트엔드 연동

문제
회원·책장 API와 화면을 따로 개발해, 로그인 정보와 요청·응답 형식을 같은 기준으로 맞춰야 했습니다.
해결
저는 공통 API 명세에 맞춰 회원·책장 API를 구현하고 기능별로 통합했습니다. 프런트엔드 담당자는 이를 로그인과 책장 화면에 연결했습니다.

작품은 팀이 함께 만든 결과물입니다. 각 기록에는 제가 맡은 백엔드 작업을 구분해 적었습니다.
